# 📄 PDF/Image OCR & Translation Studio

Эта программа всё ещё в разработке, по сути это бета-версия.

Мощное десктопное приложение для распознавания текста (OCR), извлечения таблиц и перевода документов. Программа создана как бесплатная альтернатива ABBYY FineReader с упором на работу с чертежами, схемами и скриншотами интерфейсов.

## ✨ Основные возможности

*   **Гибридный OCR-движок**: Поддержка PaddleOCR (локально, быстро), EasyOCR (локально) и Mistral OCR API (облако).
*   **Редактор зон (ROI)**: Ручное выделение областей с поддержкой поворота (0°, 90°, 180°, 270°), инверсии цвета и умных подложек (программа подбирает цвет фона под текстом).
*   **Автопоиск зон**: Автоматическое определение текстовых блоков.
*   **Распознавание таблиц**: Алгоритм (OpenCV + нейросети PaddleOCR) для таблиц с объединенными ячейками.
*   **Пакетная обработка**: Обработка целых папок за один раз.
*   **GPU-ускорение**: Поддержка NVIDIA CUDA.
*   **Гибкий экспорт**: PowerPoint, Word (3 режима), Adobe InDesign и Illustrator.
*   **Инструменты перевода**: Экспорт в JSON и сборка финального документа с переводом.

## 📦 Режимы экспорта

1.  **MS PowerPoint (.pptx)**: Накладывает распознанный текст поверх оригинальной картинки.
2.  **Word (две колонки)**: Режим для переводчиков. Левая колонка скрыта, правая видна.
3.  **Word (документ)**: Аналог FineReader. Создает «живой» документ с текстом и таблицами.
4.  **Adobe InDesign / Illustrator**: Экспорт с сохранением слоев (Оригинал, Плашки, Текст).

## 🚀 Установка и запуск

### 1. Требования
*   Python 3.11 или выше.
*   (Опционально) Видеокарта NVIDIA с поддержкой CUDA.

### 2. Установка зависимостей
Склонируйте репозиторий и установите пакеты:
```bash
git clone https://github.com/ваш_никнейм/pdf_ocr_app.git
cd pdf_ocr_app
python -m pip install -r requirements.txt
```

### 3. Установка GPU-версии PaddlePaddle (Рекомендуется)
Если у вас есть NVIDIA, установите GPU-версию для ускорения в 5-10 раз:
```bash
python -m pip uninstall paddlepaddle
python -m pip install paddlepaddle-gpu==3.0.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/
```

### 4. Запуск
```bash

python main.py
```

## 🛠️ Как пользоваться

1.  Откройте PDF, PNG или JPG через кнопку «Обзор».
2.  Нажмите «Зоны OCR» для ручной разметки или «📊 Найти таблицы» для авто-поиска.
3.  Настройте OCR (движок, язык, пороги).
4.  Выберите формат экспорта (PPTX, DOCX и т.д.).
5.  Нажмите «ЗАПУСТИТЬ ЭКСПОРТ».

## 🏗️ Структура проекта

*   `app/` — Оркестратор пайплайна (`pipeline.py`), пакетная обработка.
*   `core/` — Ядро программы (загрузчики, слияние боксов, OCR-движки).
*   `exporters/` — Модули сохранения результатов (PPTX, DOCX, InDesign, Illustrator).
*   `translate/` — Экспорт/импорт JSON для перевода.
*   `ui/` — Интерфейс на PyQt6, редактор зон, окно проверки.
